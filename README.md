# Mystery Face

A two-player face-guessing deduction game (celebrities, custom photos or names). Online with a friend, or pass-and-play on one screen.

- `node --test`: rules tests. `node tests/two-browsers.mjs http://127.0.0.1:8765/`: a real online game in two headless browsers.
- `node tools/pwa-check.mjs`: offline copy and fresh-build checks.
